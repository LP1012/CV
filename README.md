# Curriculum Vitae: Liam M. Pohlmann
This repository contains my CV source files.
To view the most-recent PDF file, see [https://lipohlmann.github.io/CV/](https://lipohlmann.github.io/CV/).
This PDF is built using a GitHub action on every push to the repository.
Otherwise, anyone is welcome to clone the repository and build the PDF themselves using the provided `Makefile`.
Note that an up-to-date version of [TexX Live](https://www.tug.org/texlive/) is required to build from source.

Thank you for your interest, and thank you to [Dr. Katy Huff](https://github.com/katyhuff/CV) for the source files from which this repository was based off of.
